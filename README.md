# Los-Temerarios

**Programación de videojuegos**

## Presentación del Equipo

Somos un equipo de estudiantes de Ingeniería de Software interesados en el desarrollo de videojuegos, la tecnología y la creación de experiencias digitales. Buscamos aplicar nuestros conocimientos de programación, diseño y desarrollo de software para crear proyectos interactivos que combinen una buena jugabilidad con soluciones técnicas eficientes.

## Intereses Generales

- **Diseño de experiencias interactivas:** Creación de mecánicas de juego que incentiven la exploración, la estrategia y la toma de decisiones por parte del jugador.
- **Programación y desarrollo:** Construcción de sistemas organizados, funcionales y eficientes que permitan un buen funcionamiento del proyecto.
- **Narrativa y experiencia del jugador:** Desarrollo de historias y elementos visuales que complementen las mecánicas y ayuden a generar una experiencia más atractiva.
- **Trabajo y organización:** Uso de herramientas como Git para mantener un control adecuado de las versiones, organizar el trabajo y facilitar la colaboración entre los integrantes del equipo.
